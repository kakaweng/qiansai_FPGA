# 路口横道与行人位置关联修正（2026-11-02）

本轮针对 PIE `set01/video_0003.mp4`、`video_0004.mp4` 中左侧和中间行人被放到错误横道的问题。修改预览端，不更换模型，不修改 FPGA 或 RK3568 服务程序。

**同日后续修正：**原先把无法定位的人移入小窗的处理，会让 `0004` 53 秒附近的真实横穿者在主场景消失，已撤销。现在保留真实检测人形、用虚环表示估计位置，加入背景运动补偿后的连续横穿分析；路口左下直接显示当前行为和独立的 PIE 预测状态。详见 [PEDESTRIAN_BEHAVIOR_PREVIEW.md](PEDESTRIAN_BEHAVIOR_PREVIEW.md)。下文验证记录是首次空间关联修改的记录，后续行为版以新文档为准。

## 具体变化

| 原问题 | 现在的处理 |
| --- | --- |
| 直接把画面左、中、右的行人映射成左/车前/右横道 | 先从同源斑马线分割建立局部横道带，再根据行人脚点与该带的距离关联；角色由横道带估计 |
| 新行人沿用邻近人群的横道，初始归属一直锁定 | 删除人群归属扩散；新的可配对几何可以修正旧轨迹，保留目标编号 |
| 中间的路边行人被强行放进远端横道 | 无横道支持时保留人形，以原图左右位置和框高估计示意位置，用虚环标识；不冒充真实横道接触 |
| 引擎盖反射的标线被用于定位 | 预览关联只采用图像高度 45%～93% 的横道像素；下沿省略代表无法判断，不代表道路无行人 |
| 为分开图标，将人沿横道拉开 2.4 个示意单位 | 删除这种物理坐标挪动，位置沿实际关联横道的左右范围插值 |
| 未能归属横道的近处行人被当成无冲突 | 对足够大、较近、位置未确定的行人，普通本地预演保持确认；远小路侧目标只观察，不直接升级为礼让 |
| 尚未开始预演就提示路线无冲突 | READY/PAUSED 卡片显示操作说明或位置待确认，不显示通行结论 |

脚点附近的少量像素/检测框误差允许局部接近关联；接近而未直接支持时，横道区域需要连续观测确认。只连接相邻且方向、深度一致的分割碎片，不用全图凸包填满路口。真实脚点接触、局部接近以及无法关联保持区别。

## 时间与权限边界

- 对象和横道必须同 producer，源时间差不超过 350ms。
- 局部几何展示期限最多 1250ms；重复报文不续期，过期报文不能在下一次刷新重新变新。
- 旧目标可继续淡化显示最多 2.6 秒，最多外推 1 秒；新 mask 与旧框无法对齐时，不拿新 mask 强行重定位旧框。
- 真实接触依据仍要求板端行人接触与对象、横道序列和时间一致，并在 750ms 内；后续行为版可用 1.5 秒内的背景补偿横穿证据触发本地示意礼让，文案明确标注“运动推测”。
- 模拟右转继续按路径行人关系判断；不增加右转灯型设置。
- 这些修改控制本地 2.5D 预演，不改变板端驾驶许可、实际车辆控制或模型新鲜度阈值。

## 应用

保持已经运行的板端服务，关闭旧预览。在 Ubuntu 依次执行：

```bash
bash /mnt/hgfs/pcie_host/update_junction_alignment_preview.sh
```

看到 `JUNCTION_ALIGNMENT_PREVIEW_PASS` 后：

```bash
bash /mnt/hgfs/pcie_host/preview_pie_anticipation.sh
```

启动器会把 `junction_association.py` 等新文件复制到 Ubuntu 本地工作目录。此轮无需重新运行模型集成、转换或板端部署脚本。按 `M` 打开路口视图；`J/I/L` 选方向，`G` 开始，`B` 暂停，`R` 重置。

## 验证与实际能力

Windows 使用已有 YOLO、Mapillary ONNX 完成两段视频共 51 次真实源画面采样（含重复对照时间点），包含 0003 的 315～338 秒，以及 0004 的 50～66 秒和 150～162 秒关键片段。完整 148 项自动回归通过，最终显示调整复查相关 63 项通过；三段连续离线预演共 240 帧，模拟 900ms 交付延迟，未发现越过程序所判定冲突的帧。以上不构成真实横道归属准确率指标。采样结果与界面图保存在 `rk3568_crosswalk_deploy/alignment_review/`。复现工具为：

```powershell
.\.venv-lane\Scripts\python.exe tools\review_junction_alignment.py --video F:\waymo_data\pie\set01\video_0004.mp4 --times 54 58 160 --output rk3568_crosswalk_deploy\alignment_review\custom
.\.venv-lane\Scripts\python.exe tools\render_junction_alignment.py --samples rk3568_crosswalk_deploy\alignment_review\custom\samples.json --output rk3568_crosswalk_deploy\alignment_review\custom_preview
```

自动回归覆盖几何关联、同横道不同图像位置、左右路边/中间目标、反光剔除、时间差与重复报文、旧轨迹归属修正、路线冲突、普通识别界面及保持逻辑。真实模型离线采样不等于 RK3568 实测，也没有用示意布局验证真实路口拓扑的准确率。

**能力限制：**现有模型在 0003 的部分路口几乎没有分割出可用的真实横道。此时保留 YOLO 检出的行人，允许清楚标注的位置估计和连续运动推测，不能从缺失的横道恢复精确位置。四向道路与横道仍为示意模板；横道角色、沿横道位置属于估计，不是经过相机标定的真实地图。后续若要让这些片段也稳定落到真实横道，需优先补这些具体场景的横道/路缘标注并改善分割。
