板端数据、HTTP 动作、快捷键与 `p1_presentation()` 的时效/保持规则不变。视频坐标、黑边排除、拖框、蓝框和按钮命中统一由 `front_p1_preview.P1Layout` 计算。离线检查图（构造状态，非板端识别结果）：`python tests/render_front_p1_preview.py`，输出 `ui_preview_front_p1/index.html` 与各状态 PNG；`python tests/smoke_front_p1_http.py` 检查本地 HTTP 下回调不阻塞。实机效果与 Ubuntu 帧率待验收。

| v2修改 | 具体规则 |
|---|---|

| 灯色时效 | 接受最多750ms年龄的推理结果；已确认颜色显示最多保持1.5秒。模拟通行要求选定目标、当前有效绿色证据，绿色证据有效期1秒 |
| 车道保持 | 每侧最后一次已确认的线型保持最多1.5秒，标注“保持”；未知和重复模型帧不延长期限，新确认的线型直接更新，断流/停止立即清除 |

## 本版功能

| 功能 | 行为 |
|---|---|
| 选方向、选灯 | J/I/L 选择路口左转/直行/右转；直接点击对应LIGHT。只有一盏候选灯时G可确认该灯并请求起步，多灯时需点击指定 |
| 红停绿行 | G 提交模拟起步请求；红灯、黄灯、未知保持停车；选定灯连续3个不同推理结果为绿色且跨度≥200ms后模拟20km/h通行 |
| 灯色变化 | 首个红/黄证据停止模拟行驶；绿色缺失时可保持颜色显示，但暂停模拟通行；有效绿色证据年龄超过1秒撤销通行和方向LED |
| 强行行驶报警 | F 模拟强行行驶10km/h、持续最多2秒；红/黄/未知灯色时报警；B 停车并清除报警，G 可重新提交起步请求 |
| 方向显示 | 屏幕箭头与虚拟LED：LED0左转、LED1直行、LED2右转；正常模式仅绿色通行时点亮 |
| 变道反馈 | A/D 请求左/右变道，持续10秒；实线阻止并报警，虚线需人工确认。短时漏检保持原反馈并注明，超过1.5秒才转为边界待确认 |
| 退出与截图 | X 停止辅助判断，B 模拟停车，K 取消变道请求；S 截图，Q 退出预览 |

行人和车辆继续显示识别框。本轮不增加检测到行人就停车的规则，不改变 A1 的车道确认与保持参数。路口转向与跨线变道是两种独立请求。

## 第一次安装

前提：共享目录已挂载、HDC已连接、驱动已加载，沿用当前已通过检查的 `lane_style.rknn` 与 `road_objects.rknn`。关闭旧预览后，在Ubuntu执行：

```bash
sudo -v && bash /mnt/hgfs/pcie_host/integrate_front_p1_rk3568.sh
```

脚本先跑规则、真实HTTP/UDP、预览回归测试，构建本地C校验加速，编译独立P1视频程序和控制器，再检查模型、切换服务。成功标志为 `FRONT_P1_PASS`。不下载模型、不训练、不重新转换，不需要Windows受控播放器或同步中继。

另一个Ubuntu终端：

```bash
bash /mnt/hgfs/pcie_host/preview_front_p1.sh
```

Windows保持把正前方视频全屏送到HDMI，分辨率仍按现有1920×1080链路。P1读取原始HDMI图像推理，再缩小到853×480有效画面置于1280×480画布中央。鼠标选灯只作用于有效画面，不包含黑边；框坐标转换回原始HDMI比例。

## 同窗演示顺序

1. 按空格开始辅助判断。该按钮不会暂停、回放或重启Windows上的视频。
2. 灯色会自动显示。若需演示模拟行驶，在路口片段按 I 选择直行，或 J/L 选择左/右转。模型尚不自动判别箭头方向。
3. 只有一盏候选灯时，按 G 确认该灯并起步；多盏灯时直接点击对应LIGHT框，再按 G。T仅显示点选提示，也可以拖框选择。蓝框跟随选定目标移动。
4. 红/黄灯车速为0，选定绿色连续确认后为20km/h；回到红/黄/未知时停止。显示为“绿灯（保持）”不代表允许依据旧证据继续通行。
5. 可在红/黄灯时按 F 演示强行行驶报警，再按 B 停车清除。虚拟车速只演示状态，不改变预录视频的实际运动。
6. 清晰直路按 A/D 验证实线、虚线和未知三种请求反馈。虚线反馈不等于单路已确认安全可变道。

每次换视频、跳转片段可按 C 恢复自动识别。指定的灯持续丢失1.5秒后解除绑定并撤销起步请求；不会因为固定30秒计时清除正在跟随的灯，也不会根据漏检推断灯已熄灭或处于闪烁。

## 重启、日志及回退

已安装P1后，RK3568重启仍先恢复共享挂载、HDC和驱动；不必重新编译：

```bash
sudo -v && bash /mnt/hgfs/pcie_host/deploy_front_p1_rk3568.sh start
bash /mnt/hgfs/pcie_host/preview_front_p1.sh
```

预览运行时获取日志：

```bash
sudo -v && bash /mnt/hgfs/pcie_host/deploy_front_p1_rk3568.sh log
```

控制日志包含 `P1 direction=... bound=... signal=... reason=... speed=... led=... alarm=... lane=...`。它只在状态变化时记录；模型耗时仍见视频服务日志。整合错误日志为 `rk3568_front_p1_deploy/integrate.log`。

恢复之前的 `scene_v4 + A1`：

```bash
sudo -v && bash /mnt/hgfs/pcie_host/deploy_front_p1_rk3568.sh rollback
bash /mnt/hgfs/pcie_host/preview_hdmi_lane_fast.sh
```

独立程序名为 `pcie_multivideo_server.front_p1`、`rk_front_p1_control`，部署目录为 `rk3568_front_p1_deploy`。不覆盖现有 `scene_v4`、`front_v1`、`scene_sync_v5` 或 `drive_v6` 二进制。
